# 🌤️ WeatherRU v1.0.0 — плагин погоды для TrafficMonitor (РФ) 

Лёгкий плагин для **TrafficMonitor**, который выводит актуальную температуру для любых городов России без регистрации, API-ключей и VPN.

## ✨ Основные возможности
- **Города России из коробки:** 50 встроенных городов РФ в выпадающем списке + ручной ввод **любого** населённого пункта (автопоиск координат через Open-Meteo Geocoding API с приоритетом `RU`).
- **Минималистичный вывод:** отображает только температуру (например, `-1 °C` или `+5 °C`) без лишней подписи — аккуратно встаёт рядом с иконкой погоды в кастомных скинах.
- **Гибкое форматирование:** в настройках можно включить/отключить знак `+` для плюсовой температуры и округление до целого градуса.
- **Без спама запросами:** обновление идёт в отдельном фоновом потоке раз в **10 / 15 / 30 / 60 минут** (при обрыве сети повтор через 2 минуты).
- **Работает в РФ без VPN и ключей:** используется бесплатный [Open-Meteo API](https://open-meteo.com/) и системный WinHTTP.
- **Никаких лишних зависимостей:** статическая линковка CRT (не требует установки VC++ Redistributable).

## 📦 Установка
1. Скачайте архив под вашу разрядность TrafficMonitor из блока **Assets** ниже:
   - `WeatherRU-x64.zip` — для 64-битной версии (рекомендуется, проверено на **TrafficMonitor v1.86 x64**).
   - `WeatherRU-x86.zip` — для 32-битной версии.
2. Полностью закройте TrafficMonitor (**ПКМ по виджету → Выход**).
3. Распакуйте `WeatherRU.dll` в папку `plugins` рядом с `TrafficMonitor.exe` (стандартный китайский `Weather.dll` лучше удалить).
4. Запустите TrafficMonitor.
5. Откройте **ПКМ → Управление плагинами → Погода РФ (WeatherRU) → Настройки**, выберите город, нажмите **Проверить** и сохраните (**ОК**).
6. Включите отображение в **Настройки отображения → Основное окно → Погода (РФ)**.

## 🎨 Привязка к кастомному скину (`skin.xml`)
Если в вашем скине уже есть иконка погоды (облако), замените ID стандартного плагина погоды в файле `TrafficMonitor\skins\<ваш_скин>\skin.xml` внутри блока `<plugin_map>` на `WeatherRU_Temperature`:

```xml
<plugin_map>
	<time>ra1YX2g1</time>
	<weather>WeatherRU_Temperature</weather>
</plugin_map>
