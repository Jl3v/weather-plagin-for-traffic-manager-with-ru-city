# WeatherRU — плагин погоды для TrafficMonitor (города России)

Лёгкий C++-плагин для TrafficMonitor, который отображает **только актуальную температуру** для любых городов России без регистрации и API-ключей.

## Возможности
- **50 встроенных городов РФ** в выпадающем списке + **ручной ввод любого города России** (автопоиск координат через Open-Meteo Geocoding API).
- **Только температура** (`+5 °C`, `-12 °C`) без лишней текстовой подписи — идеально ложится рядом с иконкой облака в скинах.
- **Защита от частых запросов**: сетевой запрос выполняется в отдельном фоновом потоке раз в **10 / 15 / 30 / 60 минут** (по умолчанию 15 мин). При обрыве сети повтор выполняется через 2 минуты.
- **Без зависимостей**: использует встроенный WinHTTP, работает в РФ без VPN, статическая линковка CRT (не требует установки дополнительных библиотек).

## Как собрать готовую DLL без установки Visual Studio (через GitHub Actions)
1. Создайте новый репозиторий на GitHub (можно приватный).
2. Загрузите в него все файлы из этого архива (сохраняя структуру папок, включая `.github/workflows/build.yml`).
3. Перейдите во вкладку **Actions** → выберите **Build WeatherRU Plugin** → дождитесь завершения сборки (1–2 минуты).
4. Внизу страницы сборки в разделе **Artifacts** скачайте `WeatherRU-x64` (или `WeatherRU-x86`, если у вас 32-битный TrafficMonitor).
5. Положите `WeatherRU.dll` в папку `plugins` внутри каталога TrafficMonitor и перезапустите программу.

## Настройка в TrafficMonitor
1. ПКМ по виджету → **Управление плагинами** → выберите **Погода РФ (WeatherRU)** → **Настройки**.
2. Выберите город из списка или введите свой и нажмите **Проверить** → **ОК**.
3. ПКМ по виджету → **Настройки отображения** → вкладка **Основное окно** → поставьте галочку напротив **Погода (РФ)**.
